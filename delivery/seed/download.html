Baixar CaraCore Seed (Windows)

Você será redirecionado para a página de Releases. Baixe o arquivo caracore-seed.exe (ou o instalador versionado disponível) e, se desejar, o arquivo de checksum para verificação de integridade.

Na página do Release você encontra:

  • caracore-seed.exe (ou nome do instalador da versão) — executável para Windows
  • checksum.sha256 — para validar o arquivo (quando disponível)
  • Notas da versão e CHANGELOG na descrição do release

Para verificar o SHA-256 no PowerShell: Get-FileHash -Path .\caracore-seed.exe -Algorithm SHA256. Compare o resultado com o valor em checksum.sha256.
