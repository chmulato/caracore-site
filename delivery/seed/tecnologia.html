Tecnologia local

Stack 100% no seu ambiente: desktop Windows, banco local, sem dependência de nuvem. Escopo filtrado ao que faz sentido para o Seed.

Shell desktop: Electron

O CaraCore Seed é distribuído como aplicativo Windows usando Electron. A interface do usuário roda em uma janela nativa; o backend (Java) sobe localmente e é acessado via HTTP na própria máquina. Nada é enviado para a nuvem — tudo roda no seu PC.

Backend: Java (JAX-RS + JPA)

O núcleo de regras de negócio e API REST é em Java (JAX-RS, JPA). O servidor sobe na máquina local (WAR em Tomcat embarcado ou launcher próprio). Requisito: Java 17 (ou runtime embarcado no instalador, quando disponível).

Persistência: SQLite

Todas as informações de licenças, usuários e configurações ficam em um banco SQLite no disco. Apenas SQLite está no escopo do produto; outras tecnologias de banco de dados não são suportadas. Sem dados na nuvem. Backup = copiar o arquivo do banco; restauração = colocar o arquivo no lugar. Ideal para operação offline e controle total dos dados.

Plataforma: Windows 10/11

O foco de entrega é Windows 10 e 11 (64 bits). O Electron gera um executável instalável (.exe / instalador); o usuário não precisa configurar servidor nem internet para o dia a dia. Escritório ou campo — desde que tenha um Windows, o Seed funciona.

API REST local

A API REST do Seed escuta em localhost (ou na interface de rede da máquina). Outros sistemas na mesma rede (por exemplo, PDV no mesmo PC ou em outra estação) podem consultar e validar licenças via HTTP. Tudo permanece na sua infraestrutura.

Portal de controle e LGPD

O Seed oferece um portal de controle das licenças (inspirado no Minerador 4.0): transparência com o cliente e tratamento de dados em conformidade com a LGPD. O espírito é o de Contador de Licenças — o cliente vê o que possui, onde está ativo e até quando vale, sem expor dados desnecessários.

Escopo Seed: apenas tecnologias locais. Não fazem parte deste produto: nuvem, SMS, PIX, SEFAZ, integrações externas — esses recursos pertencem a outros produtos do ecossistema (ex.: PDV).
