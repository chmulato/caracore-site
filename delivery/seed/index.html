O que é o CaraCore Seed?

Centraliza a contabilidade de clientes e licenças do ecossistema Cara Core (PDV, Minerador 4.0, Reino OIDC, Hub) em um aplicativo Windows Desktop (Electron + SQLite), 100% offline. É uma ferramenta de uso interno — não é produto comercializado.
