================================================================================
SALA — Referências de links relativos (para cópia)
================================================================================

Contexto: artigos LinkedIn (retro) estão em sala/redes/retro/ (articles.html, articles/).

--------------------------------------------------------------------------------
1. LINKS DENTRO DE SALA (mesma pasta)
--------------------------------------------------------------------------------
  De: qualquer .htm / .html na raiz de sala/
  Para:
    index.htm       — Controle (plano e campanhas)
    facebook/facebook.html   — Campanha Facebook
    instagram/instagram.html  — Campanha Instagram

  Uso: href="index.htm" | href="facebook/facebook.html" | href="instagram/instagram.html" | href="linkedin/linkedin.html"
  LinkedIn (Sala): linkedin/linkedin.html. Índice retro: redes/retro/articles.html

--------------------------------------------------------------------------------
2. LINKS PARA O RETRO (dentro de sala)
--------------------------------------------------------------------------------
  De: arquivos em sala/facebook/, sala/instagram/, sala/linkedin/ (artefatos 2026_*)
  Para:
    ../redes/retro/articles.html     — Lista de artigos (índice retro)
    ../redes/retro/articles/XXX.html — Artigos individuais

  Uso: href="../redes/retro/articles.html" | href="../redes/retro/articles/2026_04_28_article_78.html"

  De: sala/redes/face/ ou sala/redes/gram/
  Para retro:
    ../retro/articles.html  — equivale a sala/redes/retro/articles.html

--------------------------------------------------------------------------------
3. ASSETS DENTRO DE SALA (pasta assets/)
--------------------------------------------------------------------------------
  De: HTMLs de campanha em sala/facebook/, sala/instagram/, sala/linkedin/ (ex.: 2026_03_02_ink_facebook_mar.html,
      2026_05_01_campanha_lucratividade_mai.html)
  Para:
    assets/css/articles.css    — Folha de estilo
    assets/svg/NOME.svg        — Ícones e artes (frases Ink, pilares)

  Uso (na raiz de sala/): href="assets/...". Nos subfolders (facebook/, instagram/, linkedin/): href="../assets/css/articles.css" | src="../assets/svg/..."
  Cópia: copiar a pasta sala/assets/ junto com sala/; os links são relativos
  ao arquivo que referencia, então desde que a estrutura sala/assets/ seja
  mantida, continuam válidos.

--------------------------------------------------------------------------------
4. ESTRUTURA MÍNIMA PARA CÓPIA AUTOCONTIDA
--------------------------------------------------------------------------------
  Se quiser que a cópia funcione sem depender de ../ :

  Opção A — Copiar junto com o pai:
    docs/
      articles.html
      articles/
      sala/          ← copiar esta pasta + assets + todos os .html

  Opção B — Copiar só sala/ para outra raiz:
    nova_raiz/
      sala/          ← mesma estrutura (index.htm, linkedin/, facebook/, instagram/, assets/, etc.)
      articles.html  ← colocar no mesmo nível que sala/
      articles/      ← colocar no mesmo nível que sala/

  Os links ../articles.html e ../articles/ assumem que "sala" e "articles"
  são irmãos (mesmo diretório pai).

--------------------------------------------------------------------------------
5. ARQUIVOS QUE USAM CADA TIPO DE LINK
--------------------------------------------------------------------------------
  Links internos (sala): index.htm, linkedin/linkedin.html, facebook/facebook.html, instagram/instagram.html
  Links ../articles*:    os mesmos + todos os 2026_*_*.html (campanhas)
  Links assets/*:         só os 2026_*_*.html (campanha Ink/LinkedIn/etc.)
