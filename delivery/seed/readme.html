Documentação

Visão, requisitos e links oficiais do CaraCore Seed.

O que é o CaraCore Seed?

Produto de utilidade para a Cara Core Informática: gestão de licenças para aplicações que rodam no Windows. Valor único R$ 29,90. Inclui o aplicativo desktop (Electron, 100% offline) e o portal de controle das licenças, com transparência com o cliente e respeito à LGPD — inspirado na mesma filosofia do chmulatoETE Minerador 4.0.

É o Contador de Licenças dos clientes que compram os produtos Cara Core (PDV, Minerador 4.0, Reino OIDC, Hub): centraliza ativações, validades e acesso, tudo no seu PC, sem nuvem.

Requisitos

  • Windows 10 ou 11 (64 bits)
  • Java 17 (se o instalador não incluir runtime embarcado)
  • Não exige servidor de banco de dados — usa SQLite local
  • Não exige internet para operação diária

Links úteis

  • caracore-seed-releases — Repositório público de releases e instalador.
  • Releases — Versões e CHANGELOG.
