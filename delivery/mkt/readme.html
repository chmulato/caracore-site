O que é o CaraCore MKT?

Uma Esteira de Organização de Trabalho: Sala de Notícias (planos e campanhas — pública), Portal (acesso controlado) e oficina (6 assistentes em Python que sincronizam, organizam e validam). O foco é o colaborador (jovem em formação): os assistentes retiram o peso das tarefas repetitivas; o sistema é auditável e desenhado para privacidade (LGPD). Uso fora das normas éticas bloqueia o acesso à sala. Imagens e artefatos por e-mail a suporte@caracore.com.br no template padrão. Ferramenta de uso interno — não comercializada.

Onde está cada coisa

Sala (conteúdo, pública): D:\dev\caracore-site\sala — HTML, planilha, regis, prompts-ia, facebook/, instagram/, linkedin/, assets/, entrega/. A Sala de Notícias é pública. Oficina (scripts): D:\dev\caracore-mkt (Python). Delivery (esta página): caracore-site/delivery/mkt.

Requisitos e links

Python Baseline (Microsoft Store) para a oficina. Na sala (pública): ESTRUTURA_SALA.txt, LEIA_PRIMEIRO_REPOSITORIO.txt, opera-sala.html. No portfólio: referência ao MKT (não vendemos).
