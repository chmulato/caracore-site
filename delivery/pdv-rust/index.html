Cara Core PDV Desktop (Rust + Tauri)

Iniciativa de produto desktop do ecossistema CaraCore PDV: explorar as qualidades de Rust (segurança de memória, performance) e Tauri 2 (shell desktop moderno, binário enxuto) com instaladores em Português do Brasil, SQLite local e operação Bunker para a loja de bairro.

Dois PDVs Desktop, mesma família: o PDV Desktop (Java · JavaFX) permanece a oferta madura em pdv.caracore.com.br (canal v3.1.2-free, Windows · Linux · macOS). Esta linha Rust + Tauri é também desktop, release v0.1.0, piloto Windows — faixas distintas, sem substituição.
Loja e download Baixar v0.1.0 PDV Desktop Java

Por que Rust + Tauri 2

  • Rust: segurança de memória, binário nativo enxuto, concorrência previsível
  • Tauri 2: shell desktop leve (WebView2), empacotamento MSI/NSIS pt-BR
  • React: interface operacional moderna, mantendo dados locais em SQLite
  • Mesmo posicionamento de negócio (PME, operação local) — stack diferente da linha Java

Para quem é o piloto

  • Lojas piloto Windows com acompanhamento Cara Core
  • TI que prefere MSI pt-BR ou quer avaliar Rust/Tauri na prática
  • Quem busca performance e artefatos reprodutíveis (SHA256, manifesto)

Duas linhas PDV Desktop — mesma filosofia Bunker

Ambos são aplicativos desktop instalados no computador da loja — dados locais, operação Bunker. A diferença está na stack e no alcance: Java (Windows · Linux · macOS, oferta madura) e Rust + Tauri (piloto Windows). O posicionamento V3 de negócio (PME, PIX Split 2027) vale para ambas. Os números de release são independentes: Java v3.1.x ≠ Rust v0.1.x.
