🏗️ Arquitetura do Sistema

Componentes Principais

Backend Python

API REST em Flask hospedada no Azure App Service, implementando 8 endpoints OAuth 2.1.

  • Validação PKCE obrigatória
  • JWT com validação completa
  • Rate limiting inteligente
  • Auditoria de segurança

Frontend JavaScript

SPA com controle de sessão avançado, notificações visuais e logout seguro.

  • Session Manager automático
  • Sistema de toasts (30+ msgs)
  • Modal de logout (2 opções)
  • Acessibilidade WCAG 2.1 AA

Fluxo de Autenticação

  1. Usuário clica em "Entrar com Google/Microsoft"
  2. Frontend gera code_verifier (PKCE) e redireciona
  3. Usuário autentica no provedor (Google/Microsoft)
  4. Callback retorna com authorization_code
  5. Backend troca code por access_token + id_token
  6. JWT validado (issuer, audience, expiração, PKCE)
  7. Sessão criada com refresh token rotation
  8. Auto-refresh 5 min antes de expirar
  9. Logout revoga tokens no backend e provedor

🔒 Segurança Enterprise

PKCE Obrigatório

Code challenge SHA-256 em todos os fluxos OAuth

HTTPS Enforcement

Redirecionamento automático HTTP → HTTPS

Security Headers

HSTS, CSP, X-Frame-Options, X-Content-Type-Options

Rate Limiting

10-30 req/min por endpoint, proteção contra brute-force

Auditoria Completa

Logs de todas as operações OAuth com timestamps

Token Rotation

Refresh tokens com rotação automática (OAuth 2.1)

Padrões Seguidos: OWASP OAuth 2.0 Security Best Practices, OAuth 2.1 Draft, OpenID Connect Core 1.0, PKCE (RFC 7636)
