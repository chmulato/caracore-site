Modo estático

Área restrita desativada em simulação

Este ambiente foi convertido para uma versão estática apenas para demonstrar o comportamento visual sem depender de API, Azure, Google ou Microsoft OAuth.

Login, OIDC e autenticação real foram removidos neste mock para evitar dependência de backend externo.

Objetivo

Simular um banner explicativo sem quebrar a navegação do site.

Estado

Fluxo de acesso desabilitado e interface em modo demonstrativo.

Próximo passo

Reativar o login somente quando a infraestrutura e os credenciais estiverem prontas.
