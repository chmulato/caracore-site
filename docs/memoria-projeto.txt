# Memória do Projeto — Matriz (Cara Core Informática)

Documento de referência rápida sobre o site matriz (caracore.com.br). Atualizar quando houver mudanças relevantes de estrutura, delivery ou integrações.

Data da última atualização: 2026-05-16

---

## O que é a matriz

- **Site oficial:** [https://www.caracore.com.br](https://www.caracore.com.br) (e caracore.com.br).
- **Repositório:** cara-core-site.
- **Papel:** Portfólio, delivery (portais de produto), wiki, Área 51 (autenticação OIDC), publicações. **Matriz** = apresentação completa e consultoria; **lojas** (releases em GitHub Pages) = vitrine e download.
- **Backend:** [https://caracore-backend-docker.azurewebsites.net](https://caracore-backend-docker.azurewebsites.net) — API Flask (sessões, tokens, auditoria).

---

## Autenticação e Área 51

- **OAuth 2.1 + OIDC**, PKCE obrigatório. Provedores: Google OAuth e Microsoft Entra ID.
- **Páginas:** secure/index.html (login), secure/callback.html, secure/restrita.html, secure/logout.html, admin-logs.
- **Fluxo:** Usuário → Provedor → callback com code → troca de token (navegador ou backend) → restrita.

---

## Estrutura principal (cara-core-site)

- **index.html** — Página principal. planos.html, 404.html, ecosistema.html (mapa visual do ecossistema).
- **portfolio.html** — Portfólio de produtos (âncoras: #caracore-pdv, #caracore-hub, #caracore-seed, #caracore-ink-agenda, #ru-soberano, #minerador-ete, #area-51, #circuito-ferradura, #reino-oidc).
- **delivery/** — Portais de produto (matriz). Cada subpasta = um produto/serviço.
- **secure/** — Área 51: login OIDC, área restrita, logout, painel de logs.
- **backend/** — API Flask (Azure); token_storage, session_manager, logs, rate_limiter.
- **wiki/** — Wiki interna (projetos, tecnologias, trilhas).
- **docs/** — Documentação técnica (fases, deploy, testes, AZURE_DEPLOY, etc.).
- **handbook/** — Manuais e apostilas.
- **publications/** — Artigos e livros.

## Lojas (releases) e matriz

- As **lojas** (repositórios *-releases, GitHub Pages) apontam para a matriz para “apresentação completa” e “consultoria”.
- Cada produto mantém duas camadas: **Oficina** (repositório de desenvolvimento, sem `-releases`) e **Loja** (repositório `*-releases`, vitrine pública em `docs/`).
- Lojas principais registradas: `circuito.caracore.com.br`, `oidc.caracore.com.br`, `ru.caracore.com.br`, `ink.caracore.com.br`, `ete.caracore.com.br`, além de PDV, Hub, Seed, CSO e Área 51.
- Ex.: `caracore-ink` = oficina do app; `caracore-ink-releases` = loja pública, downloads e guias de instalação.
- **Documentos de ecossistema na raiz:** ECOSYSTEM_CARA_CORE.txt, ECOSYSTEM_LOJAS.txt, COMPONENTES_LOJA.txt.
