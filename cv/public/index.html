Diretriz institucional de privacidade

Este ambiente apresenta um avatar institucional da Cara Core Informática, com supressão de dados pessoais não essenciais e uso prioritário de canais corporativos.

Eventuais registros técnicos de acesso devem ocorrer apenas para segurança, prevenção a abuso e auditoria operacional, com coleta mínima e sem exposição nominal de fundadores.

Este endpoint permanece em UTF-8 para alinhamento consistente de acentuação entre idiomas.
