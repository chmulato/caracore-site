1. VISÃO GERAL DA ESTRATÉGIA

A Cara Core Informática está construindo uma linha de produtos voltada a um público seleto e com poder de compra. A ideia central é atuar como uma fábrica de aplicativos para Windows (desktop) e de conteúdo de identidade digital, com foco em:

- Soluções que rodam no computador do cliente (Windows), com operação offline quando faz sentido.
- Transparência com o cliente e respeito à lei de proteção de dados (LGPD).
- Preços claros onde aplicável: valor único de R$ 29,90 para upgrades ou produtos de utilidade, seguindo o modelo já validado no Minerador 4.0.

Os cinco pilares atuais são: Cara Core PDV, chmulatoETE Minerador 4.0, Reino OIDC (Reino das Identidades Federadas), Cara Core Seed (Contador de Licenças) e Circuito Python (produto chamariz: curso FREE para pessoas físicas — jovens entusiastas e curiosos da programação — sob Licença MIT; instituições de ensino: licença obrigatória R$ 5,00 por aluno matriculado/mês; uso sem licença pode configurar pirataria e responsabilização legal; curso em HTML acessível online; diploma com assinatura criptográfica; repositório público de releases circuito-python-releases, sem links para repositório privado). Cada um tem um papel definido e se complementam sem duplicar ofertas.

2.8 Cara Core Seed: ferramentas de build e delivery (inspiradas no Minerador 4.0)

- Criados no repositório caracore-seed os scripts de build e publicação, na mesma lógica do chmulatoETE Minerador 4.0 (workspace-chi/scripts):
  - build_dist_local_seed.py: gera o WAR, empacota com Electron e grava electron/dist com o instalador, VERSION e checksums (MD5 e SHA-256).
  - delivery_exe_seed_releases.py: publica o instalador e anexos como Release no GitHub (chmulato/caracore-seed-releases). Usa o token TOKEN_DELIVERY_CC_SEED_TO_REALEASES (ou GH_TOKEN).
  - push_public_to_seed_releases.ps1: sincroniza o portal de delivery (site Cara Core, pasta delivery/seed) para o repositório caracore-seed-releases (vitrine), copiando index, download, tecnologia, readme, portal-controle e assets.
- Documentação em caracore-seed/scripts/README.md e referência em electron/README.md.

4. MODELO DE ESPELHO (PORTAL E VITRINE)

Para quem não é técnico: o site da Cara Core (domínio próprio) contém o portal completo de cada produto (todas as páginas, textos oficiais, upgrade quando houver). Para alguns produtos existe ainda um repositório público (vitrine) onde o cliente também pode acessar o conteúdo ou o download, de forma alinhada ao que está no portal. Isso amplia o alcance e mantém uma única mensagem.

- Reino OIDC: portal = site Cara Core, pasta delivery/oidc; vitrine = repositório reino_oidc_releases, pasta docs/. Ao atualizar o portal, sincronizar a pasta docs/ (sync_to_delivery_oidc.py --releases). Para alinhar o portal do repositório reino_oidc com a vitrine, rodar sync_vitrine_to_reino_oidc.py no reino_oidc. Links para o portfólio em formato absoluto na vitrine.
- Cara Core Seed: portal = site Cara Core, pasta delivery/seed; vitrine = repositório caracore-seed-releases (index, download, tecnologia, readme, portal-controle e assets na raiz). Para atualizar a vitrine a partir do portal: rodar push_public_to_seed_releases.ps1 no caracore-seed (copia de delivery/seed para o clone do repositório de releases). O repositório principal (caracore-seed) tem index no mesmo estilo; os três pontos (delivery, vitrine, repo) estão alinhados ao portal do Minerador 4.0.
- Circuito Python: portal = site Cara Core, pasta delivery/circuito (index com card Download → releases/latest e card Repositório público de releases → github.com/chmulato/circuito-python-releases, canal-feedback, licenca-uso, portal-escolas); vitrine = repositório circuito-python-releases, pasta docs/ (balcão, download, feedback, licença, portal escolas; card Repositório público de releases). Releases: CircuitoPython.exe, checksums e INSTALACAO.md (v1.0.0). GitHub Pages Source: /docs. Não apontamos para o repositório privado (circuito_python); apenas para o repositório público de releases e para o acesso ao curso (chmulato.github.io/circuito_python). Mensagem em ambos: FREE para pessoas físicas; instituições com licença obrigatória R$ 5,00/aluno/mês; aviso de responsabilização legal; curso em HTML e diploma com assinatura criptográfica. Ao alterar a matriz, atualizar a filial para manter mensagem e links alinhados.
