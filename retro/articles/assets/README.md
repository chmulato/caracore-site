# Assets da Sala de Notícias

Todos os recursos dos artigos ficam nesta pasta. Nos HTML em `docs/articles/*.html` use sempre caminhos relativos a partir da pasta do artigo:

- **CSS:** `assets/css/articles.css`
- **Imagens:** `assets/img/<nome>.png` (ex.: `assets/img/article_75_01.png`, `assets/img/logo.png`)
- **Prompts de imagem:** `assets/prompts_img/` (uso interno)

Estrutura:

- `css/` — folha de estilo compartilhada dos artigos
- `img/` — imagens dos artigos (hero, logos, ilustrações)
- `prompts_img/` — textos de prompt para geração de imagens
