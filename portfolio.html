CaraCore PDV

O primeiro PDV pronto para a Reforma Tributária 2026-2033. Foco localhost e Windows Desktop (EXE sobe em localhost:8080). Instalação simples, banco apenas SQLite, funciona sem internet e oferece planos Free e Premium.

Java 21 Spring Boot SQLite Windows Desktop Bootstrap 5 HTMX ApexCharts Docker

Visão Executiva

O CaraCore PDV é uma solução completa de Ponto de Venda para o mercado brasileiro e o primeiro PDV preparado para a Reforma Tributária 2026-2033: o motor fiscal acompanha automaticamente as mudanças de alíquotas até 2033. Escopo: foco localhost e Windows Desktop — instalador EXE; ao abrir, o servidor sobe em localhost:8080. Banco apenas SQLite.

Benefícios de Negócio:

  • Motor fiscal que atualiza sozinho as alíquotas até 2033
  • Pix Split para repartir automaticamente impostos e taxa de serviço
  • Foco localhost e Windows Desktop: EXE sobe em localhost; banco apenas SQLite — ideal para pequenos e médios negócios
  • Painel de segurança e backup: políticas, criptografia e cópias automáticas para nuvem ou pendrive
  • Dashboard com vendas semanais, produtos mais vendidos e indicadores em tempo real
  • Continua vendendo quando a internet cai (modo contingência com SQLite local + SMS); ativação da licença Premium por SMS no celular do operador
  • PIX com QR Code e confirmação em tempo real; estrutura para Mercado Pago e PagSeguro
  • Leitor de código de barras pela câmera e atalhos de teclado para agilizar o caixa
  • Interface adaptada para celular, tablet e computador
  • Multi-loja, relatórios em PDF, conformidade LGPD
  • Planos Free e Premium: Free — 100 vendas/mês, 10 SMS de recibo/mês; Premium — recuperação de senha por SMS, e-mail e relatório automático ao contador (diário), suporte prioritário com acesso remoto e botão Ajuda no menu
Licenciamento: Software proprietário da Cara Core Informática. Disponível sob licenciamento comercial para empresas. Consultoria especializada disponível para implantação, migração de dados e suporte contínuo.

Para Leigos

O CaraCore PDV é um sistema de caixa para lojas, como os de supermercados. Foco localhost e Windows Desktop: o instalador EXE sobe em localhost ao abrir. Já está preparado para as mudanças de impostos que vêm no Brasil entre 2026 e 2033.

Pense assim: Na hora da compra, o sistema:

  • Calcula os impostos sozinho

  • Divide o pagamento entre você, o governo e a taxa (quando a lei permitir)
  • Mostra relatórios de quanto entrou e quanto saiu de imposto
  • Funciona em computador, tablet e celular

É como um caixa inteligente que:

  • Organiza as informações para você ver o resultado do negócio

chmulatoETE Minerador 4.0

Simulador de Hidrometalurgia Seletiva: aplicando a Engenharia de Processos de Efluentes no refino de Terras Raras. Campo Largo: instalação Windows, checksums e upgrade Ouro 4.0.

Python Streamlit Hidrometalurgia ETE Terras Raras PyTest Windows

Visão Executiva

O chmulatoETE Minerador 4.0 é um simulador que aplica a robustez e a modularidade das Estações de Tratamento de Efluentes (decantação fracionada, lodos ativados, tanques em cascata) ao refino de concentrados e soluções ricas de lixiviação (PLS) para separação seletiva de lantanídeos.

Benefícios de Negócio:

  • Arquitetura ETE transferida para refino mineral: escalabilidade modular e OPEX competitivo
  • Instalador Windows (.exe) validado por testes automatizados (PyTest)
  • Checksums SHA-256 e MD5 para verificação de integridade do instalador
  • Upgrade Ouro 4.0: módulo Mineração desbloqueado via PIX e ativação por license.key
  • Laboratório Campo Largo: rochas, Python e química — jornada para mentes jovens
  • Documentação técnica: apostila de P&D, artigo executivo, painéis de convergência e decantadores por pH
Licenciamento: Software proprietário da Cara Core Informática. Versão gratuita (Minerador 4.0) e upgrade comercial Ouro 4.0: R$ 29,90 (valor único). Soberania técnica para Mineração e Hidrometalurgia Especializada.

Para Leigos

O Minerador 4.0 é um aplicativo que simula, no computador, o processo de separar e refinar minerais valiosos (terras raras) usando a mesma lógica das estações de tratamento de efluentes: tanques em série, decantação e controle de pH.

Pense assim:

  • Baixe o instalador para Windows, execute e explore cenários de refino sem risco
  • Entenda pureza comercial, gramas de óxido por tonelada e margem bruta
  • Versão gratuita completa; upgrade Ouro 4.0 desbloqueia o módulo Mineração (PIX + chave)
  • Material de apoio: manual em PDF, laboratório virtual Campo Largo e painéis interativos

É uma ferramenta de simulação que:

  • Reduz a barreira de entrada ao refino com investimento fracionado e escala modular
  • Viabiliza jazidas economicamente marginais com a metodologia ETE
  • Entrega soberania técnica ao setor de mineração e hidrometalurgia

Área 51 - Sistema de Autenticação Enterprise

OAuth 2.1 OIDC PKCE
Software proprietário da Cara Core Informática. Este é um sistema de autenticação enterprise em produção. Apenas a apresentação e documentação técnica (Wiki) são públicas no GitHub Pages.

Aplicação Prática do Reino OIDC

A Área 51 é a implementação real e em produção dos conceitos ensinados no Reino OIDC. Um sistema de autenticação enterprise-grade que protege áreas restritas do site da Cara Core.

Visão Executiva

Sistema de autenticação e autorização corporativa com controle granular de acesso, auditoria completa e painel administrativo. Permite que apenas usuários autorizados acessem áreas exclusivas do portal, com integração nativa aos provedores Microsoft e Google.

Impacto no Negócio: Redução de 100% de acessos não autorizados, tempo de resposta inferior a 200ms, e conformidade total com padrões OAuth 2.1 e OIDC. Sistema auditável para compliance LGPD e segurança da informação.

Para Leigos

Imagine um prédio com várias salas. Algumas salas são abertas ao público, mas outras precisam de autorização especial. A Área 51 é como o sistema de segurança desse prédio: você usa sua conta do Google ou Microsoft (que você já tem) como um "crachá digital", e o sistema verifica se você tem permissão para entrar nas áreas restritas.

Analogia: É como usar sua conta do Google para entrar em um aplicativo, mas com uma camada extra de segurança: mesmo tendo conta do Google, só entra quem estiver na "lista VIP" do sistema. O administrador pode adicionar ou remover pessoas dessa lista a qualquer momento.

Recursos Principais
  • Autenticação Dupla: Google e Microsoft Entra ID
  • PKCE Obrigatório: Proteção contra ataques de interceptação
  • Lista de Autorização: Controle granular de acessos
  • Painel Admin: Gestão de usuários e permissões
  • Sistema de Solicitação: Usuários podem pedir acesso
  • Auditoria Completa: Logs de todos os eventos de acesso
  • Super Admin: Gestão de senhas e administradores
  • Conformidade LGPD: Consentimento obrigatório e gestão de dados
  • API Documentation: Swagger/OpenAPI completo
  • Persistência Azure: Armazenamento persistente de dados
  • Refresh Tokens: Sistema de renovação automática com criptografia AES-256-CBC
  • Sessões Persistentes: Usuários permanecem autenticados sem reautenticação manual
  • Deploy Azure: Alta disponibilidade e escalabilidade
