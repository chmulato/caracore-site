Para Pessoas Leigas

Este Wiki foi criado para explicar nossos projetos de tecnologia de forma simples e acessível. Aqui você encontrará:

  • Explicações claras sobre o que cada projeto faz
  • Analogias do dia a dia para conceitos técnicos
  • Exemplos práticos de como nossos sistemas funcionam
  • Glossário ilustrado de termos técnicos

Para Estagiários da Cara Core

Como novo membro da equipe, este Wiki será seu guia para:

  • Entender nossos projetos e suas tecnologias
  • Aprender como contribuir para o desenvolvimento
  • Conhecer nossas práticas de desenvolvimento e manutenção
  • Seguir tutoriais passo a passo para configurar ambiente

Nossos Projetos Principais

Conheça os projetos principais da Cara Core Informática e suas tecnologias:

CaraCore PDV

Para Leigos: Sistema de caixa (ponto de venda) para lojas, com PIX, preparado para a Reforma Tributária e modo offline quando a internet cai.

Para Estagiários: Aplicação Java/Spring Boot com Thymeleaf, HTMX, Bootstrap 5, PostgreSQL, H2/SQLite para offline e contingência.

Java 21 Spring Boot PostgreSQL Bootstrap 5 HTMX
Ver Detalhes

CaraCore Hub

Para Leigos: Sistema que conecta diferentes programas e dados, como um "centro de controle" da empresa.

Para Estagiários: Aplicação Python com APIs REST para integração de sistemas.

Python Flask Docker
Ver Detalhes

CaraCore Seed

Para Leigos: "Semente" ou modelo base para criar novos projetos rapidamente.

Para Estagiários: Template/boilerplate para acelerar desenvolvimento de novas aplicações.

Python Templates Git
Ver Detalhes

Reino OIDC

Para Leigos: Jogo educativo que ensina sobre segurança de logins na internet.

Para Estagiários: Projeto open source educacional sobre OAuth 2.1 e OpenID Connect.

OAuth 2.1 OIDC Educação
Ver Detalhes

Área 51

Para Leigos: Sistema de segurança que controla quem pode acessar áreas restritas do site.

Para Estagiários: Sistema de autenticação e autorização enterprise em produção.

Flask JWT Azure
Ver Detalhes

Python Training

Para Leigos: Curso completo que ensina jovens a programar criando jogos e projetos.

Para Estagiários: Plataforma educacional proprietária com 40h de conteúdo Python.

Python Pygame Educação
