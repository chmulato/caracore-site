## CaraCore PDV — duas linhas desktop

| Linha | Oficina | Loja | Release |
|-------|---------|------|---------|
| Java · JavaFX | caracore-pdv | pdv.caracore.com.br | v3.1.2-free |
| Rust + Tauri 2 | caracore-pdv-rust | **rust-pdv.caracore.com.br** | v0.1.0 |

- Ambos desktop, SQLite local, filosofia Bunker. **Nenhuma substitui a outra.**
- Portfólio: `#pdv-coexistencia` (comparação única) · `#caracore-pdv` · `#caracore-pdv-rust`
- Rust: **sem** delivery na matriz · redirect `/delivery/pdv-rust` → rust-pdv · loja **sem SEED**
- Discurso: evitar "PDV v3" sozinho; v3.1.x (Java) ≠ v0.1.x (Rust) ≠ V3 negócio (PME)

## Redirects (legado delivery)

Conteúdo comercial **não** vive em `delivery/` — só regras em `_redirects`:

- `/delivery/pdv-rust/*` → https://rust-pdv.caracore.com.br/
- `/delivery/pdv/*` → https://pdv.caracore.com.br/
