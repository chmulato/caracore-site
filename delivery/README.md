# Delivery — compatibilidade de URL (GitHub Pages)

Stubs HTML mínimos para URLs legadas `/delivery/{produto}/...` na matriz.

- **Sem vitrine** — só redirect para a loja canónica (`*.caracore.com.br`).
- Mapa: `docs/MAPA_ROTAS_DELIVERY_SUBDOMINIOS.md`
- `_redirects` na raiz do repo: mapa declarado (o GitHub Pages serve os stubs).
