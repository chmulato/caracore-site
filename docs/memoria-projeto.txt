# Memória do Projeto — Matriz (Cara Core Informática)

Documento de referência rápida sobre o site matriz (caracore.com.br). Atualizar quando houver mudanças relevantes de estrutura, delivery ou integrações.

Data da última atualização: 2026-05-31

## O que é a matriz

- **Site oficial:** [https://www.caracore.com.br](https://www.caracore.com.br)
- **Repositório:** caracore-site
- **Papel:** Portfólio, delivery (portais de produto), ecossistema, publicações, Área 51 (OIDC). **Matriz** = apresentação institucional; **lojas** (*-releases) = vitrine e download.
- **Wiki institucional:** [https://wiki.caracore.com.br](https://wiki.caracore.com.br) (repo caracore-wiki)

## CaraCore PDV — dois PDVs Desktop

| Linha | Oficina | Loja | Canal / release |
|-------|---------|------|-----------------|
| **PDV Desktop (Java · JavaFX)** | caracore-pdv | pdv.caracore.com.br | v3.1.2-free |
| **PDV Desktop (Rust + Tauri 2)** | caracore-pdv-rust | GitHub Pages (SEED) | v0.1.0 |

- Ambos são **desktop** instalados na máquina da loja. Mesmo produto CaraCore PDV; stacks distintas; **nenhuma substitui a outra**.
- Matriz Rust: `delivery/pdv-rust/` · Portfólio: `#caracore-pdv` e `#caracore-pdv-rust`
- Discurso: evitar "PDV v3" sozinho; V3 negócio (PME, PIX Split 2027) ≠ v3.1.x (Java) ≠ v0.1.x (Rust)
