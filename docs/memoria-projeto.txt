## Papel da matriz

## Modelo matriz ↔ loja

- **Matriz** = resumo executivo + CTAs → subdomínio da loja
- **Loja** = vitrine, download, wiki comercial (`caracore-*-releases/docs/`)
- **Oficina** = código (`caracore-{produto}`)
- **Não** duplicar vitrine longa na matriz; **não** usar `/delivery/` em CTAs novos

## Redirects legado `/delivery/*`

**Produção:** GitHub Pages — não aplica `_redirects` sozinho.

- **`delivery/{produto}/`** — HTML mínimo (meta refresh + `location.replace`) → loja canónica
- **`_redirects` / `vercel.json`** — para hospedeiros que suportam redirects HTTP
- Mapa: docs/MAPA_ROTAS_DELIVERY_SUBDOMINIOS.md
