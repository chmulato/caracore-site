# Espelho de delivery — CaraCore-PDV

Este diretório é o **portal de delivery do CaraCore-PDV** no domínio da **Cara Core Informática (matriz)**.

**Posicionamento:** PDV Selo Verde em **Bunker Digital** — soberania local (SQLite), operação antifrágil, **licenciamento de ativo**. Java 21 + JavaFX. Reforma Tributária 2026.
