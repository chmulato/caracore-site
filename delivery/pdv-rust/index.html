Cara Core PDV v3 (Rust)

Nova geração do ponto de venda CaraCore: Rust + Tauri 2 + React, instaladores em Português do Brasil, dados locais em SQLite e operação pensada para a loja de bairro que não pode parar quando a internet oscila.

A linha Java · JavaFX (PDV Desktop Selo Verde) permanece a oferta madura multi-plataforma (Windows · Linux · macOS). As duas linhas coexistem — escolha conforme o estágio da sua operação.
Loja e download Baixar v0.1.0 Linha Java (madura)

Para quem é

  • Lojas piloto que querem testar a nova stack nativa no Windows
  • Operações que priorizam instalador MSI/NSIS em português
  • Quem busca performance e binário enxuto com Rust

Artefatos oficiais (pt-BR)

  • NSIS — assistente em português (*-setup.exe)
  • MSI WiX — *_pt-BR.msi para TI
  • ZIP portátil com LEIA-ME-INSTALACAO.txt
  • SHA256SUMS.txt e manifesto na release
